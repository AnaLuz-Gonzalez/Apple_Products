# Análisis de precios de Productos Apple
- Descripción del proyecto
  
Este proyecto analiza los precios y las características de productos Apple durante el período 2020–2026. El objetivo es explorar la evolución de los precios, los descuentos, la disponibilidad de stock y las diferencias entre plataformas de venta.
El proyecto forma parte de mi portfolio de Analista de Datos, donde aplico herramientas de análisis, transformación y visualización para convertir datos en información útil para la toma de decisiones.

- Objetivos

.Analizar los precios actuales y de lanzamiento de los productos Apple.

.Comparar precios entre plataformas de venta.

.Examinar los descuentos y las variaciones de precios.

.Analizar la disponibilidad de stock.

.Explorar diferencias entre categorías y modelos de productos.

.Presentar los principales resultados mediante un dashboard interactivo.

- Herramientas utilizadas
Excel: limpieza de datos 

SQL Server: consultas y preparación de datos.

Power Query: transformación y limpieza de datos.

Power BI: modelado de datos, medidas DAX y visualización.
